# Docker DNS Monitor - Specification

## Project Overview

**Project Name**: pihole-docker-dns  
**Type**: Go CLI application  
**Core Functionality**: Monitors running Docker containers, extracts DNS labels, and writes local DNS entries to a file compatible with Pi-hole's dnsmasq.

## Functionality

### Core Features

1. **Docker Events Monitoring**
   - Connect to Docker daemon via Unix socket or TCP
   - Stream container events in real-time (container started, stopped, died)
   - Fallback to polling if events unavailable

2. **Container Label Inspection (Legacy Mode)**
   - Filter containers with label `dns`
   - Use label value as hostname

3. **Traefik Host Extraction (Traefik Mode)**
   - Extract hostnames from Traefik router labels
   - Pattern: `traefik.http.routers.<name>.rule: Host(\`hostname\`)`
   - Filter hosts by TLD suffix (e.g., `.internal`)
   - No `dns` label required when using Traefik mode

4. **DNS Entry Generation**
   - Output format: dnsmasq `address=/<hostname>/<host-ip>`
   - File path: configurable (default: `./dnsmasq-docker.conf`)
   - Only include running containers

5. **Host IP Detection**
   - Auto-detect host LAN IP from network interface
   - Configurable override via config/env/cli flag

6. **Configurable Options**
   - Output file path
   - Host IP override
   - Polling interval (fallback)
   - Docker daemon address
   - TLD for Traefik mode
   - Label for legacy mode

### Configuration

Via `config.yaml`:
```yaml
output_file: "./dnsmasq-docker.conf"
host_ip: ""  # auto-detect if empty
docker_host: "unix:///var/run/docker.sock"
poll_interval: 60  # seconds (used as fallback)
tld: ".internal"  # Traefik mode TLD filter (omit for legacy label mode)
```

Also supported via environment variables and CLI flags.

## Acceptance Criteria

1. Program connects to Docker daemon and lists running containers on startup
2. Generates dnsmasq format file with address entries for containers with `dns` label (legacy) or traefik hosts (traefik mode)
3. Reacts to container start/stop events and updates file
4. File format is valid dnsmasq config that Pi-hole can read
5. Configuration is flexible (file, env, CLI)
6. Traefik mode extracts all `.internal` hosts from `Host()` patterns in router rules

## Output Format

Dnsmasq compatible:
```
# Generated by pihole-docker-dns
address=/mycontainer.local/192.168.1.100
address=/otherapp.local/192.168.1.100
```
